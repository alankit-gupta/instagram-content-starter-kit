# Publish and share this kit

1. Create a GitHub repository named `instagram-content-starter-kit`. Start private while reviewing. Initialize it with a README so there is a default branch. Do not add account credentials or private assets.
2. Grant your connected GitHub app access to this repository. Share its URL in the conversation preparing the kit so the files can be uploaded.
3. Review the uploaded files. Check that only generic templates and scripts are included. Keep private brand configuration and generated logs outside the public repository.
4. Test setup on a second account: verify its exact handle, create a draft, approve one test post, confirm actual publication and then enable recurring work.
5. In the repository Settings, enable Template repository. When ready, change visibility to Public. GitHub may require owner confirmation; check the current UI.
6. Share the repository URL. Friends choose Use this template, supply their own brief, connect their own accounts and activate their own recurring task.

No GitHub Actions publishing workflow is included. GitHub does not run the ChatGPT/Metricool workflow merely because these files exist. A website or paid hosted product would be a separate project with authentication, user isolation and operational support.
